# 适用问题

用于乳房胀、局部硬块、红热痛、担心“堵奶”、症状反复，或高产出伴反复胀痛、奶流困扰和大量额外泵奶。先核对症状变化和全身风险，不把吸出更多当作恢复指标。

# 解决方案

## 1. 按风险选择当下行动

| 情况 | 当下支持 |
| --- | --- |
| 轻度胀满，喂养前后会变化，无疼痛、红热或全身症状，喂养未受影响 | 继续回应宝宝正常喂养需要，不为排空额外泵奶；不难受时无需专门处理 |
| 局部胀痛或炎症样不适稳定，尚无已知全身警示表现 | 在可耐受范围内正常喂养；乳晕胀得难含接时可少量手挤至较易含接或较舒适，避免为排空而额外泵奶；可隔布短时冷敷约 10 分钟，以舒适为限并避免冻伤；穿舒适、不紧压的内衣 |
| 发热、寒战、明显全身不适，或红肿疼痛正在加重 | 及时联系医生，按严重程度尽快就诊；可耐受的喂养/移乳与宝宝摄入保障并行，不等待记录或只依赖居家处理 |
| 反复同一位置硬块、持续肿块或症状反复 | 安排医疗检查以查明原因；即使没有发热，也不能无限延长自我观察或只当作“奶没排干净” |
| 晕厥、呼吸异常等紧急表现 | 立即建议当地急救/急诊和现场帮助，停止常规指导和追问 |

没有发热不能自动排除需要处理的问题。不能远程确定乳腺炎、脓肿或感染，也不能开抗生素。

## 2. 高产出和过度刺激

- 大量额外泵奶、反复胀痛、冰箱存量持续增加或奶流困扰，提示需要核查供需不匹配和过度刺激；不要再增加夜泵或追求彻底排空。
- 先围绕舒适喂养、宝宝实际吞咽/呛咳表现和妈妈现实目标安排专业评估。产出多不能排除宝宝摄入、乳汁转移或其他健康问题。
- 不自行给限时单侧喂养、骤减移乳、药物或草药减奶处方。需要减量时由有经验的喂养专业人员结合宝宝摄入和妈妈症状逐步制定。

## 3. 共同边界

- 不用力揉散硬块、深部按摩、震动器“通乳”、针挑白点、持续热敷或反复排空作为通用处理。
- 不突然停止全部喂养，也不因胀痛固定要求从患侧先喂或增加泵奶。
- 疼痛妨碍移乳时，尽早取得帮助并保障宝宝摄入；药物问题交由医生或药师结合个体情况判断。
- 已就诊者按医嘱复评，症状变差时提前联系，不自行改药。

# 复评与转介

- 复评看疼痛、红肿范围、硬块变化、全身状态和喂养影响；吸出更多不等于炎症改善。
- 局部炎症样不适在上述低风险支持后 12–24 小时仍不改善，应联系医生；恶化随时提前。这个观察窗口不适用于已有全身症状、明显恶化或正常无痛胀满。
- 症状消退、喂养舒适且没有待处理风险时可以结束；反复发作或持续同一位置肿块需要专业复核，不重复同一自助方案。
