# 适用问题

用于产后初期不知道怎样建立泌乳、希望增加产出、可比泵量下降、漏掉移乳机会，或希望在混合喂养和休息约束下维持现状。先确认宝宝摄入安全，再讨论妈妈想改善的结果；“想追奶”不等于已经证实低供给。

# 解决方案

## 1. 产后初期建立

- 解释初乳量少与成熟乳阶段不同，但不能因此保证宝宝一定吃够。
- 母婴清醒且可安全照护时，可进行肌肤接触、回应早期觅食信号并帮助舒适含接。
- 健康足月新生儿常见每天喂养约 8–12 次或更多；这只是背景，不代替吞咽、尿便和生长评估，也不是每位妈妈必须完成的次数、上限或补奶处方。
- 暂时不能有效亲喂或母婴分离时，尽早请助产士或喂养专业人员协助有效喂养、手挤奶或舒适吸奶。挤出乳汁和既有补充方案用于保障宝宝摄入，不能让宝宝等待妈妈“追上奶量”。
- 出生第 1–4 天不能套用第 5 天尿布参照。少尿与吃奶耐力差同时出现时，应当天联系照护团队；难以唤醒、呼吸异常等立即急诊。

## 2. 产出下降或希望增加

- 先统一比较条件：完整还是部分时段、吸奶次数、距离上次移乳时间、是否亲喂后、单双侧、是否漏记、设备或配件是否改变。
- 一次或短期测得减少，只说明该次条件下测得不同；选下一次原本需要发生的可比喂养或吸奶观察，不额外加泵做测试。
- 持续可比变化，或确有母乳覆盖差额且用户希望增加时，优先修复已发现的低效环节，例如含接困难、疼痛，或替代喂养时漏掉的移乳机会。
- 只调整一个有依据、现实可行的环节。保留现有安全补充喂养，不承诺“几天追到多少”，不统一规定加泵频次、固定夜间间隔或长时泵奶。
- 产后大出血、乳房手术、用药、内分泌或其他健康变化只是需要医生核查的线索，不能远程诊断病因，也不能要求用户自行停药。

## 3. 尊重既有目标和特殊背景

- 用户希望维持混合喂养、减负或多休息时，围绕该目标提供帮助，不强行转成全母乳、撤补充或增加夜泵。
- 早产、患病、喂养耐力差、多胎或已有专业方案时，先沿用儿科/照护团队安排。不能把足月宝宝的频率、尿布或增长规则直接套用，也不能自行撤除强化剂或补充。
- 多宝宝分别判断摄入和生长，再讨论妈妈总的移乳负担；不平均分配产量推算每个宝宝实际摄入。
- 已有高产出、反复胀痛、奶流过快困扰或大量额外泵奶时，不继续增奶，转 `breast-fullness-and-inflammatory-symptoms`。

## 4. 避免低价值建议

不要把大量喝水、特定食物、忍痛、持续排空、无限增加吸奶次数或购买设备当成默认增奶方案。不提供催乳药物、草药或个体减奶处方。

# 复评与转介

- 按本次调整的环节观察：含接/吞咽、舒适度、漏掉的移乳机会是否恢复，或相同条件下的产出是否变化。
- 产出增加不证明宝宝摄入改善或疼痛解决；不因产出上升自动减少补充。
- 调整无效、持续可比下降、存在相关病史或宝宝摄入/生长信号时，请 IBCLC、儿科和医生按问题共同核查。
- 用户目标已满足、没有风险且不想继续观察时结束，不制造新的追奶任务。
