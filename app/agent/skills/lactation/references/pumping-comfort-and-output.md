# 适用问题

用于症状主要发生在吸奶器工作时，或用户询问罩杯、吸力、安装、漏气、配件状态和泵量变化。目标是舒适地完成实际需要的移乳，并区分设备使用、疼痛和奶量判断。

# 解决方案

## 1. 先处理疼痛和损伤

- 正在疼痛、夹压或摩擦时，先停止当次致痛操作，并按厂家说明解除负压。
- 检查乳头是否居中，是否擦壁、发白、肿胀，佩戴是否挤压。停止当次疼痛操作不等于骤停全天喂养或移乳；同时保障宝宝当前摄入。
- 症状缓解、没有损伤且用户愿意再次使用时，按该设备说明从低且舒适的吸力开始，在舒适范围内调整。持续痛立即停止，不靠提高吸力、延长时长或忍痛达到奶量目标。
- 适配不确定、反复肿胀、皮肤损伤或无法舒适移乳时，尽早请喂养专业人员或厂商核查。不能凭泵量、照片或远程描述指定精确罩杯尺寸、档位或固定时长。

## 2. 安装、配件和电气安全

- 关闭设备后，按用户手头的厂家说明核对乳汁接触部件的安装、连接、密封和耗材状态；只检查说明允许的部位。
- 不编造型号步骤，不跨品牌比较档位，不拆修电机，也不声称读取了设备数据。
- 进水、电气故障、焦味、冒烟或异常发热时立即停用，并按厂家安全说明或售后渠道处理。
- 接触乳汁的部件每次使用后按厂家说明充分清洗并晾干；不把冷藏待洗配件描述为可靠替代。消毒要求结合宝宝背景和厂家说明，区分清洗与消毒。

## 3. 吸出量变化

- 先核对相同时间窗、距离上次移乳的间隔、是否亲喂后、单双侧、次数、记录完整性和设备/配件变化。
- 一次吸出较少不代表奶量不足；部分时段不外推全天，亲喂后的泵量不代表一餐或全天产能。
- 有未测亲喂时，妈妈总产量保持未知。不能用泵量推算宝宝亲喂摄入，也不能从“设备工作正常”推出低奶量。
- 舒适度、安装和比较条件都已核对且持续可比下降时，再加载 `lactation-establishment-and-output-change`；需要判断宝宝是否吃够时加载 `milk-supply-assessment`。

# 复评与转介

- 在下一次原本需要的吸奶中，先看舒适度和皮肤表现，再在相近条件下看产出；不要为了验证原因重复致痛操作。
- 动作已完成但没有报告舒适度时，效果保持未知；泵量增加也不证明疼痛改善。
- 持续疼痛、损伤、反复肿胀、无法舒适移乳，或无法满足宝宝当前安全喂养时，应尽早取得专业帮助。
- 不追求统一 `mL/min`、固定时长或“完全吸空”；用户不再困扰且没有风险时结束。
