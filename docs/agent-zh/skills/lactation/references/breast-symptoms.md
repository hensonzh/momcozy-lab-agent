# 乳房症状

评估泌乳期间乳房胀满、发硬、局部疼痛和炎症相关症状。帮助用户缓解不适、避免加重，并判断何时需要医疗评估。

## 评估框架

不要把所有肿块或疼痛部位都称为“堵奶”，也不要根据单一症状推断感染。

结合用户的描述考虑以下维度：

1. **乳房症状**
   - 胀满、肿块、压痛、疼痛或发红的位置和范围；
   - 影响一侧还是两侧乳房；
   - 症状是新出现、持续存在，还是正在加重；
   - 是否影响平常的亲喂或吸奶。

2. **全身症状**
   - 发热、寒战、明显疲劳或类似流感的不适；
   - 剧烈疼痛、快速扩散的红斑，或其他明显加重的迹象。

3. **近期奶量和移乳变化**
   - 亲喂或吸奶间隔变长、移乳突然减少、返岗或生活规律变化；
   - 奶量过多、经常额外吸奶，或为了“排空乳房”增加刺激；
   - 同时存在含接困难或吸奶器使用问题。

根据已有信息，将情况归为：

- **可能是正常胀满或轻度乳房胀痛**
- **可能是局部炎症或与乳汁淤积有关的问题**
- **可能需要医疗评估**
- **目前信息不足，无法判断**

只询问会改变评估或下一步处理的信息。

## 服务决策

**目标是在维持适合母婴需要的移乳方式的同时缓解炎症和不适，而不是反复“排空乳房”。**

根据评估选择下一步：

- **轻度胀满或局部不适，没有明显全身症状**
  → 继续按宝宝需要亲喂，或维持原有吸奶安排。不要仅为消除肿块而频繁额外吸奶。视用户情况，冷敷可能有助于缓解不适。

- **局部肿块、压痛或发红**
  → 避免深度按摩、用力按压，或反复试图用吸奶器把乳房完全吸空。观察症状是否改善或扩散；如果局部肿块或疼痛持续不缓解，应安排临床检查，不能保证它会自行消失。

- **同时明显奶量过多**
  → 按需加载 `milk-supply-assessment.md` 或 `milk-supply-management.md`。不要简单建议增加吸奶，因为这可能进一步刺激泌乳。

- **症状可能与亲喂或吸奶方式有关**
  → 根据发生情境加载 `latch-and-nipple-pain.md` 或 `pumping-support.md`。

- **发热、寒战、明显全身不适、发红或疼痛快速加重，或者症状持续恶化**
  → 建议及时到临床医生或医疗机构接受评估，不要只依靠居家处理。

考虑母亲的疼痛、休息需要、喂养目标和实际喂养方式。如果停止不必要的额外吸奶后仍胀得难受，可以考虑少量手挤或吸出一点以缓解；不要把“不排空”理解为“绝不缓解胀痛”。不要要求她为了维持奶量而忍受显著疼痛或过度移乳。

## 图像与隐私边界

不要要求、鼓励用户提供乳房、乳头或其他私密部位的照片或视频，也不要依赖这些影像来评估。

主要依靠：

- 用户描述的症状位置、范围和变化；
- 她自己观察到的发红或肿块；
- 发热或全身不适；
- 近期亲喂、吸奶和奶量的变化。

如果仅凭文字无法可靠评估，或需要检查皮肤或肿块，应建议由临床医生或其他合适的专业人员评估。

## 回复指导

围绕三个问题组织回答：

1. **目前最像哪类乳房问题？**
2. **现在最有用的做法或应避免的做法是什么？**
3. **出现哪些变化应及时就医？**

每次优先提供一到三条重要建议。不要机械地给出完整护理流程，也不要对每一种乳房疼痛或发硬都建议用力按摩或反复排空。

## 安全与行为

- 如果出现明显发红、发热、剧烈疼痛、进行性加重或其他安全疑虑，先遵循共用安全准则。
- 如识别到紧急医疗风险、自伤风险，或伤害宝宝及其他人的风险，先遵循共用安全准则。
- 在整个服务过程中遵循共用行为准则。
