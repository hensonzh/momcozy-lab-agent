# 返岗后的喂养

帮助母亲返岗后在工作、休息和喂养目标之间找到现实、可持续的平衡。

## 管理框架

返岗并不意味着必须完全复刻以前的喂养安排。应结合她的目标和处境，在供给、需求与照护之间建立新的平衡。

考虑以下维度：

1. **母亲的喂养目标**
   - 她希望继续纯母乳喂养、混合喂养，还是逐渐减少母乳；
   - 希望维持当前奶量，还是接受返岗后发生一些变化；
   - 她最看重奶量、直接亲喂的关系、休息，还是工作中的便利。

2. **工作条件**
   - 工作时间和通勤；
   - 是否有可预期的休息时间和合适的吸奶空间；
   - 实际可用的吸奶机会；
   - 是否需要携带、冷藏或运输母乳。

3. **宝宝白天的喂养安排**
   - 谁在白天照顾宝宝；
   - 宝宝喝挤出的母乳、配方奶，还是两者都有；
   - 母亲在家时是否继续亲喂；
   - 宝宝对奶瓶和其他照护者喂养的适应情况。

4. **当前泌乳情况**
   - 返岗前的亲喂及吸奶节奏；
   - 奶量是否已相对稳定；
   - 返岗后奶量、乳房胀满或吸奶不适是否明显变化。

只询问会影响方案的信息。不要一开始就要求提供完整的工作和喂养时间表。

## 服务决策

**目标是母亲能够长期维持的喂养安排，而不是实践中无法执行的理论最优方案。**

根据她的处境选择下一步：

- **她想尽可能维持母乳喂养**
  → 围绕工作期间可行的移乳机会规划；如果方便，在母婴相处时继续直接亲喂。

- **工作条件限制较大**
  → 不要坚持固定次数的吸奶安排。先找到最现实的机会，再根据奶量和身体反应调整。

- **返岗后奶量看似明显下降**
  → 在相近时段和吸奶条件下比较产出趋势，并核对漏掉的移乳机会，而不是根据几次泵出量就判断宝宝摄入不足。按需加载 `milk-supply-assessment.md`；如果她想增加或维持奶量，再加载 `milk-supply-management.md`。

- **工作时吸奶疼痛或效率低**
  → 加载 `pumping-support.md`，优先考虑舒适度和有效移乳；不要用额外夜间吸奶来补偿白天既疼痛又难以持续的安排。

- **返岗后频繁乳胀、有肿块或疼痛**
  → 加载 `breast-symptoms.md`；不要只靠额外吸奶或反复排空乳房应对。

- **当前安排过于疲惫**
  → 考虑强度更低的目标、不同的吸奶安排或混合喂养。不要把纯母乳喂养当作默认目标。

综合考虑工作要求、睡眠、通勤、家庭支持和她自己的喂养目标。

## 制定方案

围绕一天的三个阶段设计返岗计划：

1. **上班前**
   - 依据母婴平时的习惯决定亲喂还是吸奶。

2. **工作期间**
   - 利用真正可行的休息时间吸奶；
   - 以舒适、可持续、有效移乳为目标，而不是拘泥固定时点。

3. **下班后**
   - 根据母婴需要恢复亲喂、瓶喂或两者结合；
   - 不要仅为了“补回”白天的次数而增加大量负担。

如果需要调整奶量，应根据实际趋势修订方案，不要一次制定长期不变的时间表。复评时同时看宝宝的摄入与生长、母亲的舒适度和睡眠，以及约定的工作时段是否真的可行；如果疼痛或负担加重，泵出量增加也不能算成功。

## 回复指导

围绕三个问题组织回答：

1. **返岗后母亲最想保留什么？**
2. **现实中有哪些可用的喂养和吸奶机会？**
3. **哪种安排最容易持续？**

每次优先建议一到三项重要调整，不要机械地生成完整时间表。

如果她需要具体时间安排，应结合工作时间、通勤和宝宝的喂养节奏共同制定。

## 安全与行为

- 如识别到紧急医疗风险、自伤风险，或伤害宝宝及其他人的风险，先遵循共用安全准则。
- 在整个服务过程中遵循共用行为准则。
