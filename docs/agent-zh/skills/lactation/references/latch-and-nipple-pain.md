# 含接与乳头疼痛

评估直接亲喂时的含接困难和乳头疼痛。帮助用户理解可能原因、尝试无需私密影像的安全调整，并识别何时需要专业评估。

## 评估框架

不要认为亲喂时疼痛属于正常现象，也不要只根据疼痛强度判断病因。

依据用户描述考虑：

1. **直接亲喂情况**
   - 宝宝是否容易含接，还是反复脱离并需要重新含接；
   - 宝宝是否持续吃奶并有吞咽；
   - 疼痛主要在最初含接时出现，还是贯穿整个喂奶过程。

2. **乳头表现**
   - 喂后乳头是否明显被压扁、变形、发白、破损或出血，或是否持续疼痛；
   - 症状出现在一侧还是两侧；
   - 症状一直存在、刚出现，还是正在加重。

3. **喂养有效性**
   - 喂养是否明显困难或异常耗时；
   - 母亲是否担心宝宝未能有效获得乳汁；
   - 是否同时担心奶量或宝宝摄入量。

根据已有信息，将情况归为：

- **可能存在含接或吸吮困难**
- **可能存在乳头刺激或损伤**
- **可能有其他原因需要进一步评估**
- **目前信息不足，无法判断**

只询问可能改变判断的信息，不要一次要求描述喂奶过程的所有方面。

## 服务决策

**目标是在提高有效喂养的同时减少疼痛和损伤，而不是让母亲忍痛亲喂。**

根据评估选择下一步：

- **可能存在含接困难**
  → 介绍用户可以尝试的基本调整，例如让宝宝身体更贴近母亲、等宝宝充分张嘴后再含接；之后观察疼痛和吞咽情况是否改善。

- **乳头明显受到刺激或损伤**
  → 在查找疼痛原因的同时，优先减少进一步摩擦和损伤；症状持续或加重时建议专业评估。如果她描述反复出现的白点或水泡，不要仅凭颜色判定病因，也不要建议自行挑、刺、揭开或用力挤压。

- **疼痛显著，但文字无法确定原因**
  → 不要反复猜测具体的含接问题。建议由国际认证泌乳顾问（IBCLC）或其他合适的专业人员现场或实时视频评估。

- **担心宝宝没吃够**
  → 按需加载 `infant-intake-assessment.md`；不要仅凭喂奶时长推断摄入量。

- **担心奶量不足**
  → 按需加载 `milk-supply-assessment.md`；不要将亲喂疼痛等同于奶量不足。

考虑母亲是否想继续直接亲喂、当前疼痛负担及喂养目标。不要把继续亲喂说成唯一选择。

## 图像与隐私边界

不要要求、鼓励用户提供乳房、乳头或其他私密部位的照片或视频，也不要依赖这些影像评估。

主要依据以下信息评估含接与乳头疼痛：

- 用户的文字描述；
- 疼痛何时发生、如何变化；
- 她自己能观察到的乳头变化；
- 宝宝的吃奶、吞咽和脱离乳房情况；
- 调整前后的变化。

如果这些信息不足以可靠评估，应说明限制并建议由 IBCLC、临床医生或其他合适的专业人员进一步评估。

## 回复指导

围绕三个问题组织回答：

1. **目前最可能是哪类问题？**
2. **现在可以安全地尝试什么？**
3. **何时需要进一步的专业评估？**

每次优先提供一到三条重要建议。不要机械地给出完整的含接教程，也不要让母亲忍痛喂奶。

## 安全与行为

- 如果出现乳房明显发红、发热、剧烈疼痛、进行性加重或其他安全疑虑，先遵循共用安全准则。
- 如识别到紧急医疗风险、自伤风险，或伤害宝宝及其他人的风险，先遵循共用安全准则。
- 在整个服务过程中遵循共用行为准则。
