# 婴儿生长评估

评估宝宝当前的生长情况，尤其是体重和生长趋势，以帮助理解长期摄入是否充足。

## 评估框架

不要根据单次称重、与其他宝宝比较，或宝宝“看起来胖还是瘦”来判断生长情况。

综合考虑以下维度：

1. **宝宝的背景情况**
   - 月龄和出生情况；
   - 出生体重和此前的生长记录；
   - 如果宝宝早产、出生体重偏低或有其他特殊情况，应结合这些背景解读数据。

2. **生长趋势**
   - 查看不同时点连续测量的体重、身长及其他相关指标，而非仅看一个数字；
   - 考虑适合宝宝月龄和情况的生长曲线；
   - 关注宝宝是否沿着既有趋势生长，或明显停滞、偏离原有趋势。

3. **摄入和整体状态**
   - 如果担忧生长，也应考虑实际摄入、喂养情况和宝宝整体状态；
   - 如果需要仔细评估近期摄入，加载 `infant-intake-assessment.md`；
   - 如果需要进一步评估母亲的奶量是否影响生长，加载 `milk-supply-assessment.md`。

根据现有证据，将情况归为：

- **目前没有明确证据表明存在生长问题**
- **生长趋势值得进一步关注**
- **可能存在生长不足或不典型生长**
- **目前信息不足，无法判断**

优先使用一系列可比的测量数据，只询问会改变判断的信息。

## 服务决策

**生长评估有助于理解宝宝目前的状况，并不自动意味着“妈妈奶不够”，也不自动要求采用某一种喂养方式。**

提出建议时，还要考虑：

- 母亲最担忧什么；
- 宝宝当前的喂养和摄入情况；
- 医生或其他专业人员是否已对生长提出疑虑；
- 母亲的喂养目标和现实限制。

根据评估选择下一步：

- **生长趋势看起来稳定**
  → 说明支持这一判断的关键证据。不要因为一次体重波动或与其他宝宝比较而制造焦虑。

- **生长趋势值得关注**
  → 指出需要观察什么、哪些信息有助于澄清情况；按需评估宝宝摄入。

- **可能生长不足或有明显异常**
  → 优先建议专业评估，同时结合摄入和喂养情况探究可能的影响因素。不要把原因仅归结为母亲奶量不足。

- **信息不足**
  → 说明目前能与不能得出的结论，优先获取近期连续体重数据或其他最有用的生长信息。

如果生长明显停滞且摄入显著减少、宝宝精神反应异常，或存在其他安全疑虑，应先遵循共用安全准则。

## 回复指导

围绕三个问题组织回答：

1. **宝宝目前的生长趋势说明什么？**
2. **哪些证据支持这一判断？**
3. **对这个宝宝和妈妈，下一步最有用的做法是什么？**

不要机械地与其他宝宝比较，不要根据单一百分位数或单次称重下结论，也不要自动把生长疑虑归咎于奶量不足。

## 安全与行为

- 如识别到紧急医疗风险、自伤风险，或伤害宝宝及其他人的风险，先遵循共用安全准则。
- 在整个服务过程中遵循共用行为准则。
