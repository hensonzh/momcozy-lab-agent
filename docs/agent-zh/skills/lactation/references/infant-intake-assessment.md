# 婴儿摄入量评估

评估宝宝目前是否吃到足够的母乳或其他喂养。结合宝宝所处阶段、喂养方式和实际迹象，决定是否需要进一步观察、调整喂养或寻求专业帮助。

## 评估框架

不要仅凭哭闹、频繁吃奶、单次亲喂时长或一瓶奶的量来判断摄入是否充足。

综合考虑以下维度：

1. **当前喂养情况**
   - 宝宝月龄及主要喂养方式；
   - 亲喂、瓶喂挤出的母乳和配方奶的大致安排；
   - 用实际瓶喂记录评估已知摄入量；不要根据亲喂时长推算宝宝实际喝下多少奶。

2. **摄入后的表现**
   - 结合宝宝所处阶段观察尿布和排便情况；
   - 观察宝宝整体状态、清醒程度及喂后的活动情况；
   - 偶尔一次哭闹、吃奶频繁，或很快再次寻奶，都不足以单独证明摄入不足。

3. **生长趋势**
   - 判断较长时间内摄入是否充足时，结合体重及生长趋势；
   - 如需进一步评估，加载 `infant-growth-assessment.md`。

根据现有证据，将情况归为：

- **目前没有明确证据表明摄入不足**
- **可能摄入不足**
- **目前信息不足，无法判断**

利用已知信息，只问可能改变判断的关键问题，不要一次要求完整的喂养日志。

## 服务决策

**判断宝宝是否吃够，并不意味着要求母亲必须采用某一种喂养方式。**

提出建议时，还要考虑：

- 母亲此刻最担心什么；
- 她是否想继续亲喂、瓶喂、混合喂养，或改变当前方式；
- 当前方式是否让母亲或宝宝负担过重；
- 母亲的奶量、身体状况和现实处境。

根据评估和用户请求选择下一步：

- **没有明确的摄入不足证据**
  → 说明支持判断的关键证据。不要因为宝宝哭闹或吃奶频繁就认定必须补喂。

- **可能摄入不足**
  → 优先确保宝宝吃到足够食物，并评估可能的原因。如果奶量不足可能是因素之一，也使用 `milk-supply-assessment.md`。

- **摄入疑虑同时伴有生长疑虑**
  → 加载 `infant-growth-assessment.md` 综合评估，不要只盯着某一次喂奶的量。

- **信息不足**
  → 说明现在能判断什么、还有什么未知；只询问最可能改变判断的信息。

不要假定：

**担心宝宝没吃够 = 一定需要添加配方奶。**

结合宝宝的实际情况、母亲的喂养目标和现实处境，与她一起确定下一步。

如果宝宝精神反应明显异常、难以唤醒、摄入量明显下降，或存在其他安全疑虑，应先遵循共用安全准则。

## 回复指导

围绕三个问题组织回答：

1. **已有信息是否提示宝宝吃够了？**
2. **哪些证据支持这一判断？**
3. **结合母亲的目标，下一步最有用的做法是什么？**

每次优先给出一到三项重要行动。不要机械地展示整套评估，也不要根据单一迹象下结论。

## 安全与行为

- 如识别到紧急医疗风险、自伤风险，或伤害宝宝及其他人的风险，先遵循共用安全准则。
- 在整个服务过程中遵循共用行为准则。
