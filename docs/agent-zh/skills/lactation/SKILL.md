# 泌乳 Skill

这是泌乳专业支持的入口。

结合用户请求的完整含义、当前上下文和实际需求，找出她现在最想解决的问题，然后加载最匹配的 reference 文件。

reference 文件提供各类情境下的专业评估框架和一般处理思路，而不是固定答案。应结合用户的具体情况、目标、现实限制、此前尝试和当前请求，调整判断与建议。

## 使用原则

- 首先找出用户的**主要关注点**，优先加载一份主要 reference 文件。
- 依据请求的完整含义、问题发生的情境及用户的目标来选择，不要机械地匹配某个关键词。
- 仅当可靠评估确实需要另一个专业维度时，才加载另一份 reference。不要一次加载所有可能相关的文件。
- 用户目标发生变化时，按需切换或补充 reference。

## Reference 文件

### `milk-supply-assessment.md` — 奶量评估

当主要问题是**奶量是否充足或是否意外发生变化**时加载，例如：

- 我的奶量够吗？
- 我的奶量下降了吗？
- 最近吸出来的奶变少，是不是快没奶了？
- 我的奶量正常吗？

如果评估需要进一步了解宝宝是否吃够或生长是否符合预期，按需加载 `infant-intake-assessment.md` 或 `infant-growth-assessment.md`。

---

### `milk-supply-management.md` — 调整与管理奶量

用户明确表示想要**增加、维持或减少奶量**，且主要问题是下一步怎么做时加载，例如：

- 怎么增加奶量？
- 怎么维持奶量？
- 奶太多了，怎么减少？
- 亲喂或吸奶该如何调整？

如果首先需要确定是否确实存在奶量问题，先加载 `milk-supply-assessment.md`。

---

### `infant-intake-assessment.md` — 宝宝摄入量评估

当主要问题是**宝宝是否真的吃够了**时加载，例如：

- 宝宝吃够了吗？
- 宝宝每次该吃多少？
- 喂完还哭，是不是没吃饱？
- 需要补喂吗？

评估奶量时，如果需要考虑宝宝的实际摄入情况，也可以用此文件辅助。

---

### `infant-growth-assessment.md` — 宝宝生长评估

当主要问题是**宝宝的体重或生长趋势是否符合预期**时加载，例如：

- 宝宝体重增长正常吗？
- 最近增重慢，该怎么办？
- 体重增长能说明我的奶够不够吗？

评估奶量时，如果需要考虑长期摄入情况，也可以用此文件辅助。

---

### `latch-and-nipple-pain.md` — 含接与乳头疼痛

主要问题发生在**直接亲喂时**加载，例如：

- 宝宝难以含接或含接过浅；
- 宝宝反复脱离乳房；
- 亲喂时乳头疼；
- 乳头受损、变形或明显不适。

如果问题主要发生在使用吸奶器时，加载 `pumping-support.md`。如果主要是乳房本身胀满、有肿块或疼痛，加载 `breast-symptoms.md`。

---

### `pumping-support.md` — 吸奶不适及效率

主要问题发生在**使用吸奶器时**加载，例如：

- 吸奶时疼痛、摩擦或牵拉；
- 乳头肿胀；
- 怀疑吸乳罩不合适或吸力有问题；
- 吸奶效率不佳，或觉得乳房里还有奶。

如果主要问题是整体奶量是否确实不足，按需加载 `milk-supply-assessment.md`。

---

### `breast-symptoms.md` — 乳房胀满、肿块与疼痛

主要关注点是乳房本身**胀满、发硬、有肿块、压痛或疼痛**时加载。

优先处理乳房症状，而不是先做一整套奶量评估。

如果同时存在发热、明显发红、全身不适或其他可能的医疗风险，先遵循共用安全准则。

---

### `return-to-work-feeding.md` — 返岗后的喂养与泌乳

主要问题是**返岗后或工作期间如何继续母乳喂养**时加载，例如：

- 工作时如何安排吸奶；
- 如何兼顾亲喂、瓶喂和吸奶；
- 返岗后如何维持奶量；
- 白天由其他照护者带宝宝时如何安排喂养；
- 如何规划储奶、运输及工作日的喂养安排。

如还存在具体的奶量、吸奶不适或宝宝摄入量疑虑，按需加载相应 reference。

## 组合使用 Reference

用户的问题可能涉及多个专业维度。先处理主要关注点，只在评估需要时加载其他 reference。

例如：

- “我最近吸出来的奶越来越少，宝宝增重也慢。”
  → `milk-supply-assessment.md` + `infant-growth-assessment.md`

- “宝宝吃奶时乳头很痛，我还担心他没吃够。”
  → `latch-and-nipple-pain.md` + `infant-intake-assessment.md`

- “返岗后吸出来的奶越来越少，我该怎么调整？”
  → `return-to-work-feeding.md`，之后按需加载 `milk-supply-assessment.md` 或 `milk-supply-management.md`

## 安全与行为

- 如识别到紧急医疗风险、自伤风险，或伤害宝宝及其他人的风险，先遵循共用安全准则。
- 在整个服务过程中遵循共用行为准则。
