# 泌乳 Skill：渐进加载设计

当前维护入口为 `app/agent/skills/lactation/`：

- `SKILL.md` 只保存高频问题路由、共用工作方式、事实边界、安全边界和回复标准。
- `references/*.md` 保存各高频问题的完整评估与解决方案。
- 不建立内容版本目录；每个文档以自己的 SHA-256 指纹标识。历史 Run 保留加载当时的正文快照。

当前能力支持在对话中主动识别并制定可调整的奶量或返工喂养方案；它不是已保存的产品计划。记录和个人日程仅在上一轮逐项复述并得到下一轮自然语言明确同意后，才可通过各自写工具执行；个人日程不是提醒。专题记录仍按需限量读取，不自动注入每日记录或完整历史。

## 高频问题与 reference

| 高频问题 | `reference_id` | 主要任务 |
| --- | --- | --- |
| 奶量是否充足或发生异常变化 | `milk-supply-assessment` | 判断当前供需状态，并识别需要进一步核对的摄入或生长维度 |
| 增加、维持或减少奶量 | `milk-supply-management` | 根据明确目标和现实约束制定可持续调整方案 |
| 宝宝实际摄入是否充足 | `infant-intake-assessment` | 结合喂养方式和宝宝表现判断摄入及补充评估需求 |
| 宝宝体重与生长趋势 | `infant-growth-assessment` | 评估生长信息，并辅助判断长期摄入 |
| 含乳困难和亲喂乳头疼痛 | `latch-and-nipple-pain` | 区分含乳、乳头损伤、吸吮效率和转介需求 |
| 吸奶舒适度与移乳效果 | `pumping-support` | 核对适配、吸力、操作和乳头乳房状态 |
| 乳房胀硬、肿块、红肿与疼痛 | `breast-symptoms` | 评估症状范围、变化、全身表现和医疗风险 |
| 返工后的喂养与泌乳管理 | `return-to-work-feeding` | 协调亲喂、吸奶、瓶喂、储奶与工作节奏 |

`SKILL.md` 在既有共用原则与路由上补充识别计划机会；奶量评估区分证据缺口和目标缺口，奶量管理负责已知目标下的增减奶决策，返岗专题负责可行的工作日安排与备选；不把同一套步骤复制到各层。

`SKILL.md` 不重复这些专题的完整步骤。模型确定主诉后只加载最相关的一个 reference；仅当另一专业维度确实会改变判断或下一步时才加载第二个。

## 运行时流程

1. 系统提示词只暴露 `lactation` 的简短 manifest。
2. 需要泌乳专业规则时调用 `load_service_skill`，只传 `skill_id=lactation`，取得精简路由。
3. 根据路由再次调用同一工具，并传注册表中的 `reference_id`，取得一个专题方案。
4. 每次调用只在工具回执中返回资源身份与内容指纹；所选文档作为独立 `developer` 消息写入同一 Run。
5. 当前上下文已有相同资源和指纹时不重复加载。文档被历史压缩后只剩摘要，后续需要完整规则时重新加载。

工具不接受任意路径。reference 只从应用维护目录注册；文件名、frontmatter `name`、`reference_id` 和文档交叉引用统一使用小写连接线，并要求文件名 stem 与 `name` 完全一致。`description` 必须非空。注册表按文件名排序以保证输出稳定，但该顺序不代表路由优先级，因此不维护 `order` 参数。

## 内容边界

共同规则放在 `SKILL.md`，包括：先确认用户目标、一次只补最关键资料、区分用户报告与可核算事实、不虚构记录或执行能力，以及统一的紧急风险分流。

每份 reference 保存该专题的评估框架、服务决策、回复要求与安全边界；需要图片或隐私判断的专题单独说明隐私边界。具体规则只放在相关 reference 中，避免无关问题加载全部专业正文。结构维护日期为 2026-09-24；工程验证不代表已完成临床专家审核或真实模型临床验收。

## 验证边界

确定性测试覆盖路由体积、reference 命名和注册集合、Schema 枚举、未知 reference 拒绝、内容指纹、历史重放、同事务持久化及事件类型。`evals/behavior/v1/scenarios.json` 继续覆盖奶量、疼痛、风险、能力边界和多轮跟进；同一回合可以先后两次调用 `load_service_skill`，结构断言按工具名集合判断。

`--validate-only` 只校验评测目录，工程测试只验证加载与 Runtime 契约；二者都不等于真实模型已通过临床行为评估。发布前仍需运行真实回复评审，并对疼痛、炎症、新生儿摄入和生长风险场景进行专业抽检。多轮执行与发布门禁见 [对话与跟进评测](conversation-followup-evals.md)。
