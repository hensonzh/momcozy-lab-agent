# 泌乳 Skill：专业评估流程

当前版本：`lactation v3`。这次更新把通用咨询原则改为可执行的奶量评估指令：每个维度规定所需输入、核算方法、判断边界、缺失信息时的追问和下一步。v2 文档保留；已持久化到历史 Run 的正文不会被新版本改写。

## 流程与完成条件

风险筛查 → 确定目标宝宝、日龄/出生背景、喂养目标和时间窗 → 三维评估 → 交叉核对 → 一个优先动作。

| 维度 | 必须区分的对象 | 应产出的结果 |
| --- | --- | --- |
| 生长发育 | 单次测量、可比趋势、儿保参考结论；足月与早产背景 | 有证据支持的趋势、需复核信号或资料不足，不凭体重增加判正常 |
| 实际摄入 | 提供量与喝入量、亲喂与瓶喂、全天与部分记录 | 已知可测摄入和不能量化的部分，再结合尿便、精神及生长判断风险 |
| 妈妈泌乳供需 | 挤出量、宝宝得到的量、实际用量、库存与补充来源 | 记录内收支及其限制，区分产量、移乳/转移和总摄入问题 |

完成条件不是“填齐所有字段”，而是基于已有证据回答用户的问题，指出影响结论的关键缺口，并确定下一步。信息不足时每轮只追问最重要的一项；已有风险时先处理风险。

算术只针对用户提供且口径明确的数据。例如混合喂养的未知亲喂量保持未知；全吸奶喂养的日收支不能冒充宝宝的生理需求。没有版本化生长参考数据，不生成百分位、z-score 或参考分类。这次不新增业务查询、写入、计划或外部检索工具。

## 来源与适用范围

核对日期：2026-09-19。以下来源支持临床判断边界；三维流程、证据格式、对话追问顺序和记录核算口径是应用设计，并非某一指南原文。

- [AAP：出生后 3–5 天首次就诊评估](https://www.aap.org/en/patient-care/newborn-infant-and-early-childhood-nutrition/newborn-and-infant-health-assessment-and-promotion/first-office-visit-3-5-days/)：支持结合体重、身长、头围、水合状态、尿便进行评估；出生体重下降超过 10% 是进一步评估信号，不能直接诊断低奶量或自动处方补充量。
- [CDC：新生儿母乳喂养基础](https://www.cdc.gov/infant-toddler-nutrition/breastfeeding/newborn-basics.html)：支持将吞咽、含接、体重恢复和按日龄解释的排泄表现联合考虑。新生儿观察点不外推为所有月龄通用阈值。
- [AAP：母乳喂养临床常见问题](https://www.aap.org/en/patient-care/breastfeeding/frequently-asked-questions/)：支持区分乳汁生成与转移问题，结合含接、疼痛和相关病史核查。该页面注明自身不是正式 AAP 政策，不把其中建议包装为统一诊疗标准。
- [WHO：儿童生长标准](https://www.who.int/tools/child-growth-standards/standards)：提供不同生长指标的标准资料。当前 Runtime 未加载这些参考表，因此只解释已有测量或有来源的专业结论。
- [ABM 临床方案 32：高泌乳管理](https://www.bfmed.org/assets/32%20Management%20of%20Hyperlactation.pdf)：支持关注过度刺激并个体化评估，避免把持续加泵作为默认建议；需要专业监督的限时单侧喂养等治疗不由对话自动开出。

## 验证边界

`evals/behavior/v1/scenarios.json` 增加三维综合评估、未知亲喂、全吸奶收支、部分时段、双胞胎、早产、新生儿体重下降和高产出伴不适等场景。工具加载、禁止业务副作用及事件结构使用现有确定性断言；临床解释和评估质量使用各场景的人工/模型评分要求。

`--validate-only` 只校验场景契约，工程测试只验证加载、版本、持久化等链路；二者不等于真实模型已通过临床行为评估。发布前应对新场景运行真实回复评审。
